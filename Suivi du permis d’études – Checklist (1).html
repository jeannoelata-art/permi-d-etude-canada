💻 Utiliser comme une application

Le bouton « Télécharger l’application » crée un fichier unique qui contient le site et toutes vos données. Double-cliquez dessus pour l’ouvrir, même sans internet. Pour l’avoir sur le bureau, enregistrez-le dans le dossier Bureau, ou ouvrez-le dans Chrome puis menu ⋮ → « Enregistrer et partager » → « Créer un raccourci ». Chaque modification est sauvegardée automatiquement dans le navigateur, et dans votre compte Claude quand il est disponible (accès depuis un autre appareil).
